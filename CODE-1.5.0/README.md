This version of FIRETEC uses CMake to configure and build an executable of FIRETEC for the current system.

--Requirements--
1) CMake (version 3.10 or later) 
2) Fortran compiler, current version of code has been tested on cray, gnu, and intel fortran compilers.
3) MPI libraries, current version of code has been tested on open_mpi and mpich packages.
