## Inputs
There is one main input file with an example found in this directory.

The main input file which the program will look for is called ‘gridlist’ and is parsed with variables listed in the following table. NOTE: for each variable to be correctly parsed, they need to be found in 'gridlist' as VARIABLE = VALUE (ex: nx = 200) with spaces before and after the equality and only one variable per line.
